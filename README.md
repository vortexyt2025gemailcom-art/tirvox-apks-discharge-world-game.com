# Tirvox · módulos

Subí a la raíz de un repo público (ej. `tirvox`): `core.js`, `auth.js`, `profile.js`, `apk.js`, `app.js`.

1. Repo → Settings → Pages → Branch `main` / `(root)` → Save.
2. Tu URL queda `https://TU-USUARIO.github.io/tirvox/`. Pegala en `GITHUB_BASE` dentro de `index.html`.
3. Subí `index.html` a Netlify.
4. Firebase Console → Authentication → Settings → Authorized domains → agregá tu dominio de Netlify.

Si editás un módulo en GitHub, tarda ~1 minuto en actualizarse.
